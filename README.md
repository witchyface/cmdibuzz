**Cmdibuzz**

A server-side Fabric mod for Minecraft 1.21.1 that lets you create custom commands, automate events, manage scripts, and run a lightweight economy — all through JSON configuration files. Inspired by the Bukkit plugin MyCommand.

**Features**
* Custom Commands — Define commands with arguments, permissions, cooldowns, and costs
* Event Triggers — Bind commands to join, quit, death, chat, interact, world change, and more
* Scripting — Conditionals (if/elif/else), custom per-player variables (PlayerData), operators
* Roulette — Weighted random selection from a pool of commands
* Economy — Money and item costs; supports Impactor or built-in mock provider
* Boss Bars, Titles, Particles, Sounds — Full action chain support
* MiniMessage — Color, gradient, and format tags (<red>, <gradient:green:red>, <#FF5555>)
* SQLite — Persistent cooldowns, one-time use tracking, custom variables, and balances
* Item-Attached Commands — Bind commands to items via NBT using /cmdibuzz attachcmd
